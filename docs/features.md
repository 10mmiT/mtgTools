# Features

A tab-by-tab tour of what MTG Tools does. For setup and configuration see [configuration.md](configuration.md); for how the code is laid out see [architecture.md](architecture.md).

## Available@ tab
- Shared group availability calendar — mark which days you're free
- Logged-in players are identified automatically via their linked player — no name entry needed. The "Who are you?" bar is a toolbar item at the top of the tab, and only appears for admins and in open (no-login) mode, where it's remembered in the browser
- Click any future day to toggle your availability
- Each name on the calendar is drawn in that player's own identity colour — the same one their chip wears on Players, Want Lists and Pick Night (a name with no player record, which open mode allows, gets a stable colour of its own)
- "Best upcoming days" column ranks days by how many people are free
- On mobile, the calendar switches to a compact week-list (Mon–Sun) with prev/next week navigation
- All availability data persists across restarts

## Collections tab
- Add collections from Archidekt (URL or CSV export) or Moxfield (CSV export only — their API is behind Cloudflare and refuses this server, so a pasted Moxfield collection link is turned down where it is pasted, with the export named as the way in)
- Results table shows card name, which printings the shelf holds, a column per collection, and a total; scrolls horizontally when many collections are loaded
- **Which printings are on the shelf.** A card's row says which editions the copies behind its quantity are — `2× C21, 1× XM ✦`, with the foils marked. It stays one row per card: the breakdown is a summary, and a specific printing is looked at on the card itself. **Every way a collection gets onto a shelf records it.** An Archidekt import takes the set, the collector number and the finish off the pages it was fetching anyway, so a shelf gains this by being re-imported and not by a single extra request. **Both CSV exports carry it too**, checked against real ones: Archidekt's names the Scryfall ID outright, and Moxfield's names the edition and the collector number and no id anywhere in the file — which is the same identity said the other way round, so it is recorded as the printing it is. Where a row says nothing its copies land in the *unknown* entry, counted and never guessed at from the card's name; a set code with no number is unknown too, being a shelf of cards rather than a card. Until a collection is imported again it reads *unknown* the whole way down: unknown is a shelf whose printings nobody recorded, and never a shelf holding none of the card. The quantities beside it are untouched by any of this, and always add up to the same numbers they did before
  - **A shelf that does not know offers to fix itself.** A collection with no printings recorded says so above the table, with a button that re-imports it — nobody has to work out for themselves why the column reads *unknown*. **Every shelf a press can fix is offered one**, whichever way it comes back: an Archidekt shelf is fetched, and a CSV or Moxfield one — whose printings are in the export, and whose export is a file somebody chooses — opens the file picker on the same press, exactly as its `⋯` menu's **Re-import CSV** does. The strip says which of the two it is about to do. **Re-import all** appears beside the individual offers once more than one shelf can be swept without a file, and says so — *Re-import all 3 from Archidekt* — because there is one file picker and it takes one shelf at a time; the shelves it leaves keep the press of their own. An offer goes the moment it is taken and does not come back, unless the file picker is **closed without choosing anything**, which leaves the shelf exactly as it was: not updating, and offered again. A collection that already knows, one already being imported or waiting to be resumed, an empty one, and a shelf nothing can re-import at all are never offered one. **Somebody else's shelf is not yours to start** — the offer is on your own collections and the group's, and on all of them for an admin. Nothing ever re-imports itself, including when the server starts: it is minutes of somebody's rate limit, and it begins because a person pressed something. Once a fetch has started it runs on the server, so the page can be closed and the progress is still there on return
- **A collection has an owner** — chosen when it is added, changed later from its `⋯` menu — and it may have none: a shared box belongs to the group, so it counts as the group's and never as any one person's. The **Shelf** control switches the tab between *everyone's* collections and *your own*, and remembers which. Chips for collections that are loaded but off the shelf you are looking at stay on the row (their `⋯` menu is where an owner is set) and go hollow. Collections that existed before owners did have none, and nothing else about them changed
  - With no password set there is no logged-in player, so "yours" falls back to the name you type into Available@'s **"Who are you?"** bar, matched to a player. If it matches nobody the distinction is not offered at all and everything reads as the group's
  - Removing a player never removes their collections: the cards are still in the house, so the shelf becomes the group's
- **Search in Scryfall syntax.** A bare word is still a card-name search, so `sol ring` means what it always did — but the box now reads the same query language as the Scryfall tab, run against the cards you actually own: `t:creature c:r mv<=2`, `o:"draw a card" -t:land`, `r:mythic`, `t:goblin OR t:elf`, `c=wu`, `m:{G}{G}`, `is:mdfc`, `eur>=50`, `!"Sol Ring"`. Filters combine with spaces (all must hold), `-` for not, `OR` and parentheses for the rest. Supported: `name` `t`(ype) `o`(racle) `m`(ana) `mv`/`cmc` `c`(olor) `id`entity `r`(arity) `pow` `tou` `s`(et) `is`/`not` `layout` `usd` `eur`, each with `: = != < <= > >=`
  - It runs entirely on the local card database — nothing is sent to Scryfall, and typing filters ~13,000 cards in well under a frame. The first non-name search in a session pauses for a second to read the card data it needs
  - Filters that need data the local oracle-card cache doesn't carry (`f:` format legality, `a:`rtist, `year:`, `kw:` …) are refused **by name** rather than quietly matching nothing, and point you at the Scryfall tab. So are typos: `zzz:1` says *Unknown filter "zzz:"*
  - As on Scryfall, `OR` and `AND` are operators only in capitals — lower-case `or` is a word in a card name
- **Sort** by name, mana value, color (WUBRG order), power, toughness, rarity, type, price, quantity owned, or any single collection's own count — as a sentence of up to three, e.g. *Rarity → Mana Value → Name*
- **The column headers are a shortcut into the same sort.** Click a heading to make that column the sort; **shift-click** to add it as the next criterion. Clicking the column already leading flips its direction. A sorted column is marked `↑`, and a column carrying a later criterion is marked `2↑` or `3↓` so you can see where in the sentence it comes
- **Columns menu** to show/hide optional columns: Printings (on by default — it is a fact about the collection rather than one to be fetched), Mana Value, Color (as mana pips), Type, Rarity, Power/Toughness, Price (the rest off by default to keep the table clean)
- Grid view shows full card images with per-collection ownership badges
- **Pile view** draws the collection as stacks of cards on a table, cut by the **first** criterion of the sort — sort by rarity and you get four stacks of visibly different heights, by mana value and you get your curve standing up off the table, by name and it buckets on the initial letter. The rest of the sentence orders the cards *inside* each pile, so *Rarity → Mana Value* is four piles each standing in curve order. Each stack shows its count, and the table arrives with every pile already spread — clicking a pile's header settles it back into a stack. A pile starts where the pile above it ended rather than in a new row beginning under the tallest pile of the last one, so a short pile costs the table its own height and not the tallest one's
- **Size** slider beside the view toggle sizes the card art from thumbnails to full-size (grid and pile views; remembered per view)
- On mobile, defaults to grid view; list view is still available and scrolls horizontally
- **Hover any card name, anywhere in the app, to be shown the card** — and a **double-faced card shows both of its faces** side by side, since showing only the front is the preview being wrong about what the card is. Split cards and Rooms correctly show one picture, because they are one piece of cardboard; the test is the card's own, not a list of layouts. It appears only when it would show you *more* than what's on screen — a size comparison rather than a list of views, so a name in a table or a thumbnail in the deck-building drawer gets a preview and a grid tile already at full size doesn't
- Click any card name or image to open it in the **Card** tab (Ctrl/Cmd-click opens it on Scryfall instead)
- Collapsible "Add Collection" and "Collections" panels to save space; once you have at least one collection, the add panel auto-collapses (your manual toggle is remembered)
- Per-collection actions (Refresh / Re-import CSV / Remove) live in a "⋯" menu on each collection row
- On mobile, the results table is capped at 150 rows with a "Show all" button so the Deck Comparison panel is always within reach
- Right-side **Deck Comparison** panel: load a deck and see which cards you own, with a toggle to filter the table to deck cards only

## Players & Decks tab
- Add players via the **+ Add Player** button (admin only); each gets one of eight identity colours, repainted per theme so a player's chip is legible on all five (the record stores which of the eight, not a colour value)
- Add decks to players — enter a deck name and commander name; the commander's card art (fetched from Scryfall) becomes the tile background
- Optionally link an Archidekt URL to load the full card list for comparison
- Any URL can be saved as a "View ↗" link on the tile
- Each deck tile shows two primary actions — **Compare** (sends the deck to the Collections tab comparison panel) and **Build** (opens it in the Deck Builder) — with Edit, **Make private**, **Move to folder** and Remove tucked into a per-tile "⋯" menu; removing a deck asks for confirmation
- Organise decks into flat, per-player **folders** — **+ New folder**, rename and remove from a folder's own "⋯"; decks in no folder sit loose above the sections, and removing a folder drops its decks back to loose rather than deleting them
- **Drag a deck tile onto a folder** — or onto the loose zone above them — to file it there. The zone under the deck lights up as you cross it, and the one it is already in does not; a deck cannot be dragged onto another player's shelf. This is a shortcut over the "⋯" menu's *Move to folder*, not a replacement for it: the menu is the path that works on a phone, and both are offered exactly where you may edit the player
- **Make a deck private** and it reaches nobody but you and an admin — the server withholds its metadata, its card count, its cards and its history from everyone else, so a private deck is not hidden in the browser but absent from the answer. Private tiles wear a 🔒 badge, new decks are public (privacy is a deliberate act), and where the deployment has no accounts — nobody to be private *from*, and no way for the server to tell owner from stranger — neither the control nor the badge appears at all, rather than offering a lock that keeps nobody out
- **Decks you have not built yet** sit in a muted **"Not built yet"** strip at the foot of the Mine view — a row each, saying the deck's name and where it came from, with a **Build** that opens it in the Deck Builder (an Archidekt deck imports its cards on first open, and the row becomes a tile on the grid above). The grid is your *built* decks, so a deck that is only a name and a link is not on it; without the strip it would be a deck you added and could then not find. A draft is not a tile: it has no art, no card count and no shelf, and it cannot be filed in a folder until there is something in it to file
- Removing a player lives in a "⋯" menu on the player header (admin only)
- Edit any deck in-place (name, commander, link)
- The tab is one control strip — **+ Add Player** and a count of players and decks — over full-width rows of art tiles; each player is a heading carrying their identity colour, which folds their decks away when clicked
- All deck metadata and commander art URLs persist across restarts

## Scryfall Search tab
- Full Scryfall query syntax: `t:legendary t:creature`, `c:g cmc=3`, `"exact name"`, etc.
- Results show which collections own each card and in what quantity, plus Cardmarket price (EUR)
- Quick **+** button on each card to add it to your personal want list in one click
- **Sort** results by name, mana value, color, power, toughness, rarity, type, or price — as a sentence of up to three
- **List** and **Grid** view toggle
- **Size** slider beside the view toggle sizes the card art from thumbnails to full-size (grid view only; remembered per view)
- Mana costs rendered as proper MTG mana icons
- Click any card name or image to open it in the **Card** tab (Ctrl/Cmd-click opens Scryfall)
- Search on Enter or button click — no auto-search while typing to stay within Scryfall's rate limits

## Card tab
- Detailed view for a single card — on **desktop (≥900px)** clicking any card name or image opens a dimmed **modal overlay** on the current tab (close with **✕**, **Esc**, or click outside); on **mobile** it switches to the full-page Card tab (the Card tab entry is hidden in the desktop sidebar since it's only reachable via mobile)
- Shows the full card image (both faces for double-faced cards) with oracle text rendered using proper mana symbols
- Card info: mana cost, type line, power/toughness/loyalty, set · collector number · rarity · artist
- Cardmarket (EUR) and USD prices
- Format legality badges (Standard, Pioneer, Modern, Legacy, Vintage, Commander, Pauper)
- Official **rulings** for the card, pulled from Scryfall
- Links to view the card on **Scryfall** or buy it on **Cardmarket**
- **Which printings of it are on the shelf.** Above the gallery, the copies actually held: a line per printing with its count — `2× Commander 2021 (C21) #263`, `1× Mystical Archive (STA) #5 ✦` — which is the Collections row's summary written out in full, on the page where a printing is looked at properly. A shelf nobody has re-imported says `3× unknown printing` rather than showing a short list: the copies are counted, and *unknown* is never drawn as owning none. It answers for the shelf the ownership scope is set to — yours, the group's, everyone's — and says under the heading which of the three that was, so a count is never mistaken for the whole playgroup's; a card you have none of names whoever does, in their colour, the same way the mat's badges do. An app with no collection loaded at all has no shelf, and says nothing about one
- **Other Printings & Alt-Art gallery** at the bottom — every printing of the card, to the end of Scryfall's pages rather than the first 175 of them; click any one to load that specific version. Opened from a card in a deck you can edit, the same gallery **chooses** instead of navigating — see the Deck Builder's *which printing the deck runs*, below
- Ctrl/Cmd-clicking a card anywhere still opens it on Scryfall in a new tab

## Set Browser tab
- Opens on a grid of **set tiles** — every non-digital MTG set (expansions, Commander, Masters, etc.), each showing its code, year, and **how many of its cards you already own**
- Filter sets by name or code
- Click a tile to load that set's cards, with collection ownership and Cardmarket price shown inline; the set becomes a chip on the toolbar whose ✕ goes back to the tiles
- Ownership dropdown to show all cards, only owned, or only unowned
- The "N of M owned" figure is the toolbar's result count
- **Sort** by set collector number (default), name, mana value, color, power, toughness, rarity, type, or price — as a sentence of up to three
- **List**, **Grid**, and **Pile** view toggle — pile view stacks the set by the sort's first criterion, the same way Collections does, arrives with every pile spread, and lays each pile down where the pile above it ended rather than in a row as tall as the tallest one
- **Size** slider beside the view toggle sizes the card art from thumbnails to full-size (grid and pile views; remembered per view)
- Click any card name or image to open it in the **Card** tab (Ctrl/Cmd-click opens Scryfall)

## Want Lists tab
- Per-player want lists with card-name autocomplete as you type (served from the local card database)
- Admins can create a new player straight from the player dropdown ("+ New player…")
- Import (CSV: qty,name or name-only) and Export (CSV / printable PDF checklist) share one "⋯" menu in the toolbar
- **List view**: combined table across all players — who wants each card, Cardmarket price, and whether anyone already owns it
- **Player filter**: chip row under the toolbar (All / per-player, each with its card count) to narrow down to a single player's list; defaults to showing everyone, and the toolbar's count says what the filter has done ("12 of 85 cards")
- **Sort** by most-wanted (default), player (groups cards by which player(s) want them), name, mana value, color, power, toughness, rarity, type, or price — as a sentence of up to three. Most Wanted produces enormous ties by construction, so it defaults to *Most Wanted ↓ → Mana Value → Name*, which is the curve inside each block rather than one undifferentiated block per number of people who want a card
- **Columns menu** to show/hide optional columns: Mana Value, Color, Type, Rarity, Power/Toughness, Price, In Collections
- **Grid view**: card images with Cardmarket price, coloured player-initial dots (tap your own dot to remove), and ownership badges, with the same **Size** slider
- Click any card name or image to open it in the **Card** tab (Ctrl/Cmd-click opens Scryfall)
- Remove individual wants from the table view with one click
- All want lists persist across restarts

## Deck Builder tab
- Full-width editing workspace for a single deck. **Opening one is the Decks tab's job**: arrive here with nothing loaded and the mat is a signpost — *"Open a deck from the Decks tab"*, with a button that takes you there — beside **+ New Deck** (player, name, optional commander), which stays because creating one blank deck belongs where you build it
- **The deck switcher** on the strip is what is left of the old chooser: your own **built** decks, so you can step between them without leaving the mat. It is not there at all until a deck is open, whatever is open is always on it — somebody else's deck opened from the Decks tab, or a deck made a moment ago — and its first entry closes the deck and puts the signpost back. Where the app cannot say who you are, it lists every deck it can see, each named by its player
- **The deck menu, beside the mat.** The control strip had grown to fourteen things and wrapped to three rows, so it keeps only what is used while building — the deck switcher, the add-card field and the deck filter — and everything else is a column at the right-hand edge of the mat, opened from the ☰ (or `m`): **Mat** (view, size, sort), **Show** (which boards are drawn, and the missing/owned/borrowable filter with the shelf it counts against), **Look at** (Analysis, History, Compare, Categories) and **Deck** (New deck, Import CSV, Paste List, the three exports, Delete Deck). It **pushes the mat rather than covering it** — every one of those controls is answered by the mat, so a panel you had to close to see what you did would be the wrong shape — and whether it is open is remembered. Below 900px the row becomes a column and the menu takes the top of it, arriving closed. The old **⋯** popover is gone: it existed because the strip had no room
- **Delete Deck** removes the deck and its saved cards/categories entirely, so you can re-add it (e.g. re-import the same Archidekt URL from the Players & Decks tab) with a clean slate. Its history goes with it, apart from one snapshot of what the deck was as it went — an Archidekt deck re-added under the same URL finds that waiting in the History panel
- **History** drawer — what this deck used to be, and putting it back. The deck saves by replacing every card row, so before this the state a save overwrote was gone about a second after the edit. Now a snapshot is taken **once per sitting** (the first save after a few minutes' gap, holding what the deck looked like before you started), **plus one immediately before anything that can lose work** — an import, a deleted category, a bulk move, a restore, a deleted deck — tagged with which. The panel lists them newest first with the deck as it stands at the top, each row saying what changed relative to the one below it (`+12 · −1 · 3 moved`, with the card names in the tooltip), and **Restore** puts any of them back. Restoring saves the deck it is replacing first, so undoing an undo works. Kept per deck: the newest 50, and nothing older than 90 days except the last few — about 7.7 KB a snapshot for a Commander deck
- Cards grouped into categories — Commander, Creatures, Planeswalkers, Instants, Sorceries, Enchantments, Artifacts, Battles, Lands, Other by default — with custom categories, rename, and delete via each category's "⋯" menu, or all at once from the **Manage Categories** modal; deleting a category with cards in it moves them to "Uncategorised" instead of losing the grouping
- **Filter box in Scryfall syntax** — the same query language the Collections search reads (`js/cardquery.js`), run against the deck in front of you and applied live as you type: `t:creature mv<=2`, `c:r OR c:g`, `-t:land`, `o:draw`, `r:mythic`, `"exact phrase"`. A bare word is still a plain search of card name *and* rules text, exactly as this box has always worked, so nothing has to be learned to type `goblin`. A filter the local card data can't answer (`f:commander`, `a:artist`) or one that isn't a filter at all is named and explained above the cards rather than silently matching nothing, and the deck stays drawn while you're still typing. A category the filter empties keeps its header — it is still one of the deck's piles, and still somewhere a card can be dropped
- **Multiselect**: click/tap a card (List/Grid/Pile) to select it, Ctrl/Cmd-A to select all visible, or "Select all" from a category's "⋯" menu — selected cards get a **Move to…** bulk action
- **Right-click a card** (or hold a finger on it) for what can be done to it: **Inspect**, **Move to…**, **♛ Make commander**, **♛ Add as partner**, **Remove**. Grid tiles and pile cards carry no buttons of their own — the picture is the card — while list rows keep their inline ⓘ ⇄ × as well
- **Which printing the deck runs.** A card in a deck is a name, and the app draws whichever printing Scryfall calls the default. **Inspect** a card in a deck of your own and the card's *Other Printings & Alt-Art* gallery knows where it came from: it says which deck it is choosing for, rings the printing that deck runs now, prices every tile, and a press makes that printing the deck's instead of navigating to it. Close the card and the mat is drawing the art you picked, in the grid and the piles alike; the choice rides home on the deck's ordinary save and comes back with an undo. Opened from anywhere else — the Scryfall tab, a collection, a want list — the gallery is exactly what it has always been. One printing per card and not per copy: ten Forests are ten of the same Forest. **The owned count is untouched** — collections stay keyed by name, so choosing the Ravnica Sol Ring does not stop the one you own counting; whether it is *that* Sol Ring is a second question, asked beside it and never instead of it (below). The snapshot records the price **on the day you chose it**, and says so. **What you exported is what you chose**: a card with a chosen printing leaves as `1 Sol Ring (RAV) 266` on the clipboard and in the `.txt`, and fills the `.csv`'s `set` and `collector_number` columns; a card you never touched leaves as a bare `1 Arcane Signet` and lets Archidekt, Moxfield or the proxy printer decide — so a deck nobody has chosen a printing in exports exactly what it always did
- **Whether you own *that* printing.** A card in the deck wears a mark after its ownership badges saying whether the shelf has the printing the deck runs: **nothing at all** where it has, a **⇄** where the shelf has the card in some other edition, and a **?** where nobody has ever recorded which editions it holds. The mark is the *shelf's* answer and not one box's — one box holding the Ravnica Sol Ring and another holding the one the deck runs is a deck you can sleeve, so it says nothing rather than warning about the first box. A card nobody has wears no badge, as it always did. **A deck that has chosen no printing still runs one** — Scryfall's default, which is the printing the mat has been drawing all along — so the question reaches every deck and not just the ones somebody has hand-picked art in, which is nearly none of them. The wording says which: *this deck runs C21* where somebody chose it, *this deck defaults to C21* where nobody did, and the missing list reads *runs* or *defaults to* the same way — a printing the deck fell into is one to point at your own copy, and a printing somebody picked is one to think again about. A card whose data has not arrived yet is asked nothing rather than marked, so the mat never reports its own latency. The readout line adds *4 cards in another printing* beside the count when there are any — and only then — with a third section in the missing list naming what the deck runs against what the shelf has, so the choice between changing the deck's printing and buying the one it names is one you can see. **Unknown is never read as either of the other two**: every collection in existence is unknown until somebody re-imports it, so a shelf that has not been would otherwise read as the wrong edition of everything, or as empty. A copy nobody wrote down might well be the one the deck runs. Language and condition do not come into it — a lightly played German copy is still the card — but a foil is not the ordinary copy somebody paid rather less for. **The count above it does not move**, and neither does the green it turns when you own the lot: a card owned in another printing is a card you own, the printing is a second question asked beside that one rather than instead of it, and the want list, the Sets tab and the search scope all go on answering by name
- **Optimize a deck's printings, in one action.** Choosing which printing a card runs was a per-card act — open the card, scroll to the gallery, press a tile — so on a ninety-nine card deck nobody did it and the price on the readout was an accident rather than a decision. **Optimize printings…** in the deck menu walks every card on every board and proposes one printing each, in one of three modes: **Cheapest**, **Most expensive**, and **Prefer printings I own** — the latter settling the deck onto the copies actually in the box, falling back to the cheapest where you own none. **It proposes rather than acts.** The modal opens on the mode picker, shows a progress bar you can abandon at any point, and becomes the preview in place: what would change, the printing it runs now against the one it would run, the price difference per card, and what the deck would cost in the printings it proposes — the figure the price readout will actually land on, not only how far it moves, because “what would this deck cost in its cheapest printings” is the question the run exists to answer. Nothing is written until **Apply**, and the whole run lands as **one row in History** naming which mode ran, so a run that went the wrong way is one press to undo — and if that row cannot be saved, **nothing is written at all**, because overwriting every printing in a deck is only worth pressing while one press puts it back. **Cheapest and dearest are bounded to printings it is sane to go and buy** — paper, priced, not Reserved List, not oversized, not serialized, 8th Edition (2003) or later — and the bound is stated in the window, because a dearest run genuinely lands on a four-figure Sol Ring and that reads as a bug unless the question is written beside the answer. **Prefer-owned is not bounded**, because it proposes no purchase: a printing already on your shelf wins even when it is Reserved List, serialized or unpriced. **A printing nobody has quoted can never win** — unknown is not free — and a card with nothing admissible keeps whatever printing it already runs, because a run must never clear a choice. **A foil is a candidate of its own**, so a foil that is genuinely cheaper can win and one that is dearer cannot sneak in; the preview marks it with the finish by name, so an etched pick reads as etched rather than as foil. **Basic lands are left alone** in every mode — the printing of a Forest is chosen for how it looks — and cost no request. Every card the run did not touch is accounted for in one footer line by reason, and a prefer-owned run against a shelf nobody has re-imported says how many cards fell back for want of recorded printings, and names re-importing as the way out. The printings come back in a handful of requests rather than one per card — Scryfall's search takes several cards in one query — because one request per card is enough to get the whole server rate-limited for a minute, which is how the first version of this failed. If Scryfall asks for a pause anyway the run **stops and says so** rather than showing a proposal built on cards it never managed to look up. The action is **absent** on somebody else's deck, and a card that has left the deck between the preview and the press is dropped rather than written to, with the count of what actually applied reported
- **Switching commanders is one press.** ♛ **Make commander** on any card in the deck puts it on the commander board and sends whatever was lying there back into the deck, filed under the pile it belongs in. Before this it was the one thing about a deck the builder could not change: the commander board was the mat's and the deck record's commander was the Players & Decks tab's, so switching meant editing on one tab, coming back to the other and re-carrying two cards — and in between the deck's tile showed the art of a card it no longer ran. **The board is what the deck holds and the record follows it**, so the tile art, the EDHREC recommendations, the search panel's colour-identity filter and the Players & Decks tab all switch together. An **empty** board changes nothing — a deck that names a commander it has no card for yet is an ordinary deck, not one to be cleared. A snapshot is taken first, so the History panel can put the old commander back
- **♛ Add as partner** puts a second card on the commander board *beside* the first rather than in place of it — the board has always held two, which is what made partners, Backgrounds and Doctor's Companions free the day the commander stopped being a category, but the only way in was a drag onto the region. The deck goes on being named after the first of them, since the record holds one string. Offered only where it means something: with no commander it is **Make commander** instead, and with two there is no third to add
- **The legality panel says when two commanders aren't a pair.** Read off the cards rather than off a list of legal pairs: two cards may be a deck's commanders if they share a **partner keyword** (which is compared whole, so *Partner—Survivors* pairs only with another Survivor and never with a plain *Partner*), if one is **Partner with** the other by name, or if one takes a second commander of a kind the other is — **Choose a Background** with a Background, **Doctor's companion** with a Time Lord Doctor. A pair with nothing to join them is the first line in the panel, before the deck's size, because until it's fixed the 98-and-2 arithmetic underneath is about a deck that doesn't exist. A pair this app has no card data for is reported as unchecked rather than as illegal
- **Move to…** (single card or bulk) can also **✨ Auto-categorize** — sorts staples into functional categories the way Archidekt's community auto-categories do (Sol Ring → Ramp, Swords to Plowshares → Removal, etc.), falling back to card type — or create a brand-new category and move into it in one step
- **Carry a card** with the mouse or a stylus onto any category to move it there; auto-saves. The card follows the cursor with a little lag and leans into the direction it is travelling, the pile that would receive it lights up before you let go, and releasing settles it into place with a short overshoot. Released anywhere else it goes back where it came from and nothing changes. Dragging a card that is part of the current selection carries the **whole selection as a fan** with a count on it, and drops it through the same bulk move; dragging an unselected card carries that card alone and leaves the selection untouched
- Dragging is for pointing devices — a finger scrolls the mat instantly, with no press-and-hold delay, and **Move to…** stays the way to recategorise on a phone
- **The mat animates its own re-renders**: any change measures where each card was and where it ended up, and every card that moved travels there — so a removal, a sort or a move is something you watch happen rather than a result you have to work out. Only what can be seen is animated, so a four-hundred-card deck costs the same as a four-thousand-card one
- **Sort** cards within each category by name (default), mana value, color, power, toughness, rarity, type, or price — as a sentence of up to three
- **List**, **Grid**, and **Pile** view, with the shared **Size** slider for Grid and Pile (remembered per view, as on every other tab). A pile is a real stack — the face card on top with the edges of the cards beneath showing, getting visibly thicker as the category grows, so you can read the shape of a deck without counting. Each card's slight angle comes from its name, so the same card sits the same way on every render and the mat never reshuffles itself behind your back. Categories arrive spread; the arrow on a category's header settles it back into a stack. **A pile starts where the pile above it ended** rather than in a new row beginning under the tallest pile of the last one — a deck's categories run from four cards to forty, so a wrapped row used to make every short pile pay for the tallest one on it. On a real deck that is a mat a third shorter, and the same pass lays out Collections' and the Set Browser's tables of piles
- Quick **Add a card** box with card-name autocomplete (served from the local card database); **Import CSV** or **Paste List** (`1 Sol Ring` / `1x Sol Ring` / `1 Sol Ring (RAV) 266` / `// Category` lines) for bulk add — a line naming a printing is added by name, so a list this app exported pastes straight back in
- **Search / EDHREC / Lands** drawer panel — three ways of finding a card and one way of taking it, opened from the **🔍** on the strip (or `/`), beside the ☰, the fold and the `?`. It was a row in the menu while it was one search box; three tabs deep is more than a line under *Look at* can stand for, and the menu keeps only what the strip has no room for:
  - **Search** tab — Scryfall query search (with an optional commander color-identity filter, and a scope that asks the shelf instead of Magic) to find and add cards
  - **EDHREC** tab — recommendations for the deck's commander, split into the same type-based categories as Archidekt (Creatures, Planeswalkers, Instants, Sorceries, Enchantments, Artifacts, Lands) plus High Synergy, Top Cards, Game Changers, and New Cards, each with its synergy % and deck-inclusion count
  - **Lands** tab — at the top, **the check**: for each colour the deck's costs ask for, how many sources its lands make, how many the source-count table wants, and the card that set that bar — "blue: 21 sources — wants 27, for Cryptic Command". Naming the card is the point, because one triple-pip card can demand thirty-odd sources and a bare number would shout at a deck that plays fine. The requirement is read from Frank Karsten's simulated source-count table (re-run for the London mulligan and for singleton), at the row for the deck's own land count and size, so a 60-card deck gets 60-card numbers. **Only lands feed that lookup** — the simulation behind it sleeves lands and blanks, so Sol Ring and Birds of Paradise are counted and said on their own line rather than folded into a consistency the model never claimed. Behind the headline sits every card the deck's sources cannot support, for when somebody wants to argue with the number, and behind **how this is read** the panel states its own limits: the table assumes untapped sources, and Commander is multiplayer, where the on-curve deadline is softer than the model's. Folded, because small print standing over the bars on every deck is a wall in front of the finding — but two things stay in the open, the sources the table does not count and the cards it could not read, because both change what the bars mean. At the foot of the tab, one quiet line through to the **Mana Base Calculator**, which this tab did not absorb and will not: it is the only thing in the app that works with no deck loaded, and every number here is read off the deck on the mat
  - Under the check, **fix it**: for each colour the check calls short, a section that opens into the lands which would close it — everything that makes that colour, inside the deck's colours, **with the copies somebody in the house already has at the front**. That order is the one thing on this tab Archidekt could not draw, because Archidekt does not know what is in our boxes: a suggestion you can play tonight beats a better one you would have to buy. The rest is play rate, and the cut to a readable dozen never drops a land somebody has to make room for one nobody does. Basic lands are left out — sorted by play rate they would head every list, and a colour short of basics is a split rather than a search — and so is a land the deck already runs as many copies of as the format allows. A deck that clears every bar is told so, rather than shown an empty region
  - Between them, **optimize basics** — the one control on the tab that writes to the deck, and the first thing in the app to write a calculation into one. It asks for **a number of basics**, prefilled with what the deck runs now, and splits that budget across the colours in proportion to the deck's pips. Asking for basics rather than for total lands is the point: the number is a budget you set, which is what stops a mana base from crowding out the rest of the list. `{C}` sits out of the split — a deck with two colourless pips does not want two Wastes, and the slot would be taken from a colour that needed it — unless the deck has no coloured pips at all, where Wastes is the whole answer. Basics the optimizer does not write to — snow basics, anything not one of the six — **come off the budget and are named**: "3 Snow-Covered Forests aren't touched — 11 to split", so the number typed means the deck's total basics *after* this and the deck never grows behind you. Then it shows what it would do — the rows, the resulting deck size and land total, and what the check would *still* call short, "still short: blue 4 — a land, not a basic" — and applies only on a second press. The split is proportional rather than gap-driven, because the total is fixed: every Plains that fixes white takes a source from something else, and in a three-colour deck there is frequently no basic-only split that clears every bar, because the answer is duals. Applying sets quantities on the deck's own rows, so a Plains filed under a custom "Mana Base" stays there, a colour going to nought is removed rather than clamped at one, and the whole change is one redraw and one save with a snapshot taken in front of it. Beside it one override, **at least 1 basic of every colour** — off by default and remembered across decks the way the drawer's "Add to" is. "Every colour" means every colour the deck has *pips* in, not the commander's identity: a Golgari commander whose black never appears in a mana cost does not get a forced Swamp for a colour nothing asks for. It is repaired into the finished split rather than reserved out of the budget in front of it, so it is exactly a no-op on a deck whose colours were already seated, and the basic it does move comes off whichever colour is furthest above its own share. Off is the default because the proportional split is the honest answer — and the preview says the moment it would have mattered, "green rounded to 0 basics, and nothing else in the deck makes green", so you find out when it bites rather than having to know to flick a switch first. And where the budget is smaller than the deck's colour count the override says so in its own words — "a budget of 2 cannot give every colour one — white goes without" — rather than borrowing the off state's sentence for a promise it could not keep
  - Underneath it, Magic's land cycles, listed by name: shocks, fetches, triomes, painlands, pathways, creature lands and fourteen more. A section opens into that cycle's cards in the deck's colours — the commander's identity where there is one, and the union of the deck's own colours where there isn't, because "which shocklands could I run" is a fair question for a 60-card deck too. **Sections arrive closed and each fetches itself the first time it is opened**: twenty cycles fired on opening the tab would be twenty jobs in a queue the whole house shares, stalling somebody else's search to fill in cycles nobody asked to see. The second person in the house to open shocklands this afternoon pays nothing, because the Scryfall proxy caches for ten minutes
  - **Add to: Deck / Maybeboard / Sideboard** in the drawer's header, so the **+** on a card can mean *set this aside* rather than *put this in the ninety-nine*. Before this a card you were only considering had to go into the deck and be dragged back out. One control for the whole drawer rather than a menu on each of two hundred cards — choosing where cards go is a mode you're in for a while — and it's remembered. The board it fills switches on, because a card added by name has no carry and no region lighting up to receive it, so a maybeboard left switched off would answer the press with a deck that looks unchanged. The commander is deliberately not on the list: that's **♛ Make commander**, on a card already in front of you
  - **Every tab is a grid of card art** — the same `.sf-grid` the Collections, Scryfall and Set Browser tabs draw, and the same tile, so a land found by cycle carries the same **+**, ownership mark and "already in the deck" badge as a card found by searching for it. They used to be two lists of the same thing written twice, a 120px picture beside three short lines in a row 186px tall of which most was empty: four results on a screen, against EDHREC's 240 recommendations. Now about twenty
  - **Adding says it happened.** The **+** used to change nothing you could see, so a second press was the obvious thing to do and it silently made two copies. The tile now carries what the deck already holds — `✓4` on the button, and a quiet chip saying `Deck ×4` when the copies are somewhere other than where the **+** would put them. It stays pressable, because a second Forest is a real thing to want; it just can't be pressed blindly
- **The readout line**: card/land counts vs. format target (60 or 99 for Commander), average CMC and color pip counts — one thin line of what the deck *is*, which is where the numbers the rest of the builder produces end up
- **The lands figure opens the Lands tab**, where the check above lives. It used to raise a panel of its own out of the readout drawing pips against sources per colour; the check draws that same comparison with the requirement beside it and the fix underneath, and two of them ten pixels apart was the same information twice. The figure still carries the count and still says on the line when the deck asks for a colour nothing in it makes. The pips behind the number are counted off actual mana costs, commander included, with a hybrid symbol half a pip to each colour that pays it
- **Analysis** expands the curve, the type breakdown and the split out of the toolbar rather than laying them permanently across the mat, so it is there when you ask for it — including on a phone, where it used to be hidden outright
- **The frame folds, in two tiers.** One press on the ⌃ at the end of the strip hides everything you act *with* — the switcher, the add field, the filter, the whole deck menu beside the mat, the analysis strip, the bulk bar and the add-category row — leaving the readout line. A second press hides that too, for a mat with nothing on it but cards. **The strip goes with them** — it used to keep its own row standing, so folding hid the controls and reclaimed none of the 68px they sat in; the mat now rises into the space (44px back on a desktop, 117px on a phone, where the strip wraps to two rows) and the arrow floats at the top-right corner of the mat. A third brings it all back, and `c` does the same from the keyboard. Where you left it is remembered, so a deck read at full mat comes back at full mat. Nothing is ever revealed by pointing at it: the mat is a drag surface, and a card carried towards a category near the top of the screen must not trip anything
- **The ghost pile**: an empty outline after the last category, faint at rest and lit while a card is in hand. Drop cards on it and it becomes a real category with those cards in it, its name waiting to be typed in the heading it has just been given — the only way to make a category without going through a modal first. Being visible when your hands are empty is the point, and it is on the mat rather than in the toolbar, because a drop target inside chrome that folds away is one you cannot reach. Releasing a card anywhere else on the mat still means cancel
- **Boards — a maybeboard and a sideboard on the mat.** Somewhere to put a card that is not in the deck: before this, a card you were considering either went in and broke the count, or lived in your head. Each is a region below the categories, worked with the same carry — drop a card on the **Maybeboard** and it leaves the deck without leaving the deck record; drop it back on the deck, or on any category, and it is in again. **The card count, the curve, the average mana value and the export all read the mainboard alone**, so setting a card aside costs the deck nothing. **The same card can sit in a board and in the deck at once**, with a quantity of its own on each side — and carrying one onto a board that already holds it adds the copies together rather than claiming the card twice
- **Boards are off until you ask for one**, toggled from the deck menu and remembered against that deck, so a deck you never sideboard for is never asked to spend mat space on one. **A hidden board reveals itself while a card is in hand** and hides again when you let go — a board you switched off is still somewhere you can put something. On a phone, where a finger scrolls the mat rather than picking cards up, the boards are at the head of the **Move to…** list
- **A board draws flat** — one region, one count, no category headers. A maybeboard is a holding area, not a second deck. Each card keeps the category it was filed under while it lies there, so **one promoted back into the deck lands in the pile it came from** rather than arriving uncategorised
- **Compare** (in the deck menu) sends the deck to the Collections tab comparison panel

## General
- **Every tab says what it is for, once.** Arrive on one of the seven tabs that has a note — Available@, Collections, Scryfall Search, Set Browser, Mana Base, Pick Night, Deck Builder — and a short dialog opens over it: what the tab is, three or four things you would otherwise have to discover by poking, and the keys it answers to. Dismiss it (**Got it**, ✕, `Escape`, or a click outside) and **it never opens again on any device you sign in on** — the set of notes you have read is saved to your account beside the theme, and kept in the browser in open mode. Press `?`, or the **?** on the tab's control strip, to read it again; reading it again does not un-dismiss it. The four tabs left out — Card, Players, Want Lists, Admin — would only be saying their own heading back
- **`f` turns the card under the pointer over** — anywhere in the app, on any double-faced card, without reaching for its turn button. With the pointer over no card and a card open in the detail dialog, that card is the one that turns. A card with one face does nothing
- **Appearance popover** — one menu for everything about how the app looks: the theme, the playmat, and whether cards move. Opened from the sidebar on a desktop and from the nav dropdown on a phone
- **5 themes** — Dark, Light, High Contrast, Sepia, and Dusk, picked from the Appearance popover (with a checkmark on the active one). **The choice is saved to your account**, so it follows you to any device you sign in on; the browser keeps a copy too, which is what paints the first frame and what remembers the theme in open mode (no `ADMIN_PASSWORD`), where there are no accounts. A `?theme=` URL parameter (`/?theme=light`, ids: `dark`, `light`, `contrast`, `sepia`, `dusk`) overrides and replaces the saved preference — handy for sharing a link in a specific theme, or for recovering from an unreadable stored one; an unknown id is ignored
- **Playmat** — set any card's artwork as the page background by name, or upload your own image (JPEG/PNG/WebP, up to 5 MB; uploads need an account). Saved to your account like the theme, painted before the first frame, and off by default on phones with a per-device switch to turn it on
- **MTG colour theming**: each tab carries its own mana-colour accent (WUBRG + gold) on the active nav item, panel headings, focus rings, and card hover glows — independent of the 5 UI themes above, since mana symbol colours represent the game, not the chrome
- Mana symbols rendered as proper MTG icons throughout (mana-font)
- **Minimal-UI conventions across all tabs**: one shared List/Grid(/Pile) view toggle component, shared Sort, Size and Columns controls, and "⋯" overflow menus for secondary/destructive actions (collection rows, deck tiles, player headers, want-list import/export, Pick Night options) — the common path stays visible, everything else is one click away
- **Sorting is a sentence, on every card view** (Collections, Scryfall Search, Set Browser, Want Lists, Deck Builder). A sort is an ordered list of up to three criteria, each with its own direction — *Color → Mana Value → Name* — and the control is one button whose label is that sentence, opening a popover to add, reorder, flip or remove a word. **Choosing a field seeds the whole sentence** rather than giving you one word: pick Color and you are sorted colour → mana value → name without touching anything else, pick Price and the expensive cards come first. Edit the tail and the chain becomes yours — changing the first field then swaps only that word instead of re-seeding, with "Reset to suggested" as the way back. Your sort and which columns are shown persist per-view in the browser; a sort stored by an older version of the app is read as the single criterion it was, and never silently re-seeded
- **Card size** on every view that draws card art (Collections, Scryfall Search, Set Browser, Want Lists, Deck Builder): one shared slider on the tab's strip, hidden in list views, remembered per tab *and* per view — so a collection scanned at thumbnails leaves the deck you are building at the size you build it at. It replaces the old XL view, which was this question answered once at 220px and nailed to a button
- **Cards are objects, not tiles.** Card artwork is drawn with no frame around it — the picture is the card. Its shadow follows its own rounded silhouette rather than a box, a lit top edge and shaded bottom edge give it thickness, and the corners are a real card's corner as a ratio, so they stay right at every size the slider reaches
- **Pointing at a card picks it up**: it lifts, scales, leans a few degrees towards the pointer, and a sheen crosses its face. The card's layout box never changes, so the pointer can't fall off a card that grew underneath it and the grid never reflows — crossing a grid quickly leaves no trail of half-animated cards. Touch pointers never lift anything, so no hover state outlives the finger that caused it
- **Every card says whose shelf it is on.** A strip along the top edge of the card artwork, on every grid in the app: **solid green** for a card on the shelf you are asking about, **broken and in that person's colour** for one only somebody else has — go and ask them — and **nothing at all** for a card nobody in the group owns. Absence is the third state on purpose: a page of Scryfall results is mostly cards nobody owns, and a marker on every one of them is a page of markers rather than a signal. The quantity and whose box it is are on the strip's tooltip rather than on the card's face, because ×3 is illegible at the size the drawer draws a card. It sits inside the card's black border, so it covers no artwork, no title and no mana cost at any size
- **And it is the same question everywhere.** Which collections count — **Mine**, **The group's**, or **Everyone's** — is one setting for the whole app, set from the Deck Builder's strip and remembered per person rather than per browser. Before this the deck builder counted your shelf while the Scryfall search counted everybody's, so the same card could be marked as yours on one tab and as somebody else's on the next. The **Search / EDHREC drawer** is the place this was most missing: it knew a card's price, its synergy percentage, how many decks run it and which board of your deck already held it, and not whether there was a copy in a box in the room
- **And the colours are explained where the app explains itself.** The note on every tab that draws cards — Collections, Scryfall Search, Set Browser, Deck Builder, reopened with **?** — carries a legend under its points: the three states, each shown as a real swatch drawn by the same stylesheet rule the cards are, so the key cannot come to show a mark the app no longer draws
- **"Cards move" switch** in the Appearance popover turns all of that off, saved to your account like the theme. **If your operating system asks for reduced motion the whole app is still** — every transition and animation in the app is written under that guard, and the token linter fails the build on one that isn't. The system setting can only take motion away, never add it back, so it wins over the switch; the switch shows what you chose rather than silently unticking itself, with a note saying what happened
- **Scryfall traffic is centralised and cached**: the server keeps a daily copy of Scryfall's bulk card data in SQLite and serves card images/metadata/autocomplete locally; the few remaining live calls (full-text search, card detail, set browsing) go through a server-side proxy with a shared rate-limit queue and a 10-minute response cache — the browser never talks to api.scryfall.com directly
- Click any card (name or image) to open the card detail — a **modal overlay on desktop (≥900px)** or the **Card tab on mobile**; Ctrl/Cmd-click opens Scryfall instead
- **URL hash routing**: tab switches and card views update the URL (`#collections`, `#card=...`); browser **back/forward** buttons navigate between views; refresh restores your current view
- Rarely-used panels live in slide-over **drawers** opened from the tab's toolbar (Add Collection, Deck Comparison below 1280px, Deck Pool); the one thing left that collapses in place is a player's row of deck tiles, folded from the player's own header
- Per-user login system with player-linked accounts and an admin role
- **Desktop navigation**: tabs live in a collapsible left sidebar that overlays the content, with account actions (user badge, Appearance, RSS, change password, sign out) anchored to the bottom; click Collapse to shrink to icon-only mode — state persists across reloads. There's no top header on desktop — it's mobile-only
- **Mobile-friendly**: sidebar hidden on mobile, replaced by a compact dropdown plus a slim header (logo + RSS); all forms stack to full-width; inputs use a 16px font to avoid iOS zoom-on-focus; view toggles are right-aligned across all tabs

## Adding Collections

| Source | Method | Notes |
|--------|--------|-------|
| Archidekt | Paste collection URL | `archidekt.com/collection/v2/…` |
| Archidekt | Import CSV | Collection → Export → CSV |
| Moxfield | Import CSV | Collection → Download (CSV) |

Moxfield collection URLs are not supported — their API is behind Cloudflare bot protection with no public access, and answers 403 to any server. Pasting one is refused on the spot rather than started as an import that could not finish. Both exports carry their printings; Archidekt's names the Scryfall ID, Moxfield's the edition and collector number.

A collection imported from Moxfield before that — back when the tab fetched the pages itself — is re-imported **in place** from the export: its `⋯` menu offers **Re-import CSV** rather than a Refresh nothing can answer, and the file lands on the shelf it was chosen for. A CSV shelf comes back the same way, from either its `⋯` menu or the printings offer above the table, and the two are one press onto the same file picker. The shelf keeps its key, its name, its colour and its owner, and becomes an ordinary CSV (Moxfield) shelf; the cards, the quantities and the printings are the export's. It does not arrive as a second collection beside the one it was meant to replace, so nobody has to delete their own shelf to get their printings.
